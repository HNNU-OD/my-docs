
# 关于本项目

## 项目介绍

本项目是开源软件课程的个人实践项目，旨在利用开源工具构建一个静态技术文档网站，并实现自动化部署。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写技术文档 |
| MkDocs | 将 Markdown 转换为静态网页 |
| Material | 提供网站主题和导航界面 |
| Git | 管理代码与文档版本 |
| GitHub Actions | 自动执行构建和部署任务 |
| GitHub Pages | 托管静态网站 |

## 工作流程

1. 在本地编写 Markdown 文档。
2. 使用 MkDocs 生成静态网站。
3. 将项目提交到 GitHub 仓库。
4. GitHub Actions 自动构建网站。
5. GitHub Pages 发布网站。

## 实践意义

通过本项目，可以了解软件开发中的自动化构建与部署流程，为后续开发和维护开源项目打下基础。
