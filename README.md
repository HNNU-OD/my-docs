# 我的技术文档网站

本项目为湖南师范大学开源软件课程实践作业2，使用 MkDocs Material 构建静态文档网站，并通过 GitHub Actions 实现自动部署。

## 项目地址

- [在线网站](https://hnnu-od.github.io/my-docs/)
- [个人实验报告](report/README.md)

## 本地预览

安装依赖：

```bash
python -m pip install -r requirements.txt
```

启动网站：

```bash
python -m mkdocs serve
```

## 技术栈

- Markdown
- MkDocs Material
- GitHub Actions
- GitHub Pages
